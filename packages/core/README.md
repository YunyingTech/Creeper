# Creeper Core

Shared runtime for `creeper-client` and `creeper-server`. Installed automatically with either package.

Includes YAML configuration validation, bounded Selenium collection, SQLite storage, and framed JSON transport.
Python 3.10+ is required. Workers need Chrome/Chromium; servers do not launch a browser.
